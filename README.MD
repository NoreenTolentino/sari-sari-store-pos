# Sari-Sari Store POS

A point-of-sale interface for a Filipino neighborhood store, built with HTML and CSS only.

**Live preview:** 
## Features

- Product grid with prices in pesos, stock levels, and low-stock markers
- CSS-only category filter
- Receipt-style order panel with quantity steppers and totals
- Payment section for cash, GCash, and utang, with change computation
- Daily summary of sales, transactions, low stock, and receivables
- Responsive layout

## Run locally

Clone the repo and open `index.html` in a browser.
